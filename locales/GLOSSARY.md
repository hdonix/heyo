# Glossary: 简体中文 (zh_CN)

The terms that had to be decided, each with the one Chinese word Heyo uses
for it. A translation uses these and no synonym; change a term here and in
`zh_CN/LC_MESSAGES/heyo.po` together.

| English | 中文 | Why |
|---|---|---|
| Hotkey | 快捷键 | What every Chinese desktop calls a key combination that acts anywhere. |
| Shortcut, Shortcuts (the page) | 快捷键 | Chinese has one word for both; “热键” reads dated. |
| Alias | 别名 | The shell's and every launcher's word. |
| Extension | 扩展 | As browsers and GNOME say it; “插件” would promise a plugin store. |
| Command | 命令 | What an extension offers and the root search runs. |
| Palette (command palette) | 命令面板 | VS Code's term, which the people Heyo is for know. |
| Root search | 主搜索 | The search the palette opens on; “根” means nothing to a user. |
| Application | 应用程序 | The settings already say it so; “应用” only where a row has no room. |
| Favorites | 收藏 | As browsers say it; adding is 添加到收藏, removing 取消收藏. |
| Suggestions | 建议 | Standard. |
| Fallback (what a query can be used with) | 后备 | Short enough for the end of a row; “备选” would promise a choice among equals. |
| Ranking (of a result) | 排序 | Where a result stands in the list, which is what resetting it changes. |
| Activity (a live activity's row) | 活动 | Follows from Live Activity. |
| Ask AI | 问 AI | The verb people use; “询问” is stiff on a key hint. |
| Conversation, Chat (with the AI model) | 对话 | One word for both: New Chat is 新对话, AI Chat's list is of 对话. “聊天” is for people. |
| Answer (the model's) | 回答 | What was said back; 答案 is kept for the calculator's result. |
| Answer (the calculator's) | 答案 | A result, not a reply. |
| Action (in the action panel, on selected text) | 操作 | As the panel's own title says. |
| Instruction (a custom action's prompt) | 指令 | What the model is told to do; “提示词” is jargon. |
| Store (Raycast's) | 商店 | Standard. |
| Details | 详情 | Standard. |
| Configure (an extension) | 配置 | Opens its 偏好设置. |
| In Development (an extension) | 开发中 | Built by `heyo dev`. |
| Folder / Enclosing folder | 文件夹 / 上层文件夹 | Standard. |
| Show in Files | 在文件管理器中显示 | No file manager is named; it is whichever the desktop has. |
| Quick Look | 快速查看 | Apple's Chinese for the same thing. |
| Quit / Force Kill (a process, in Kill Process) | 退出 / 强制结束 | Asking it to go, and ending it whatever it says; “杀死” is not said to users. |
| Keyword (of a snippet) | 关键词 | Standard. |
| Placeholder | 占位符 | Standard. |
| Timer | 计时器 | Standard. |
| Could not … | 无法… | One wording for every failure. |
| Quicklink | 快速链接 | Raycast's own Chinese usage; says what it is. |
| Snippet | 文本片段 | “片段” alone is unclear outside code. |
| Snippet expansion | 文本片段展开 | Follows from Snippet. |
| Clipboard History | 剪贴板历史 | The system's own word for the clipboard, and no “记录” (that is Record). |
| Entry (of the history) | 条目 | Neutral; covers text, images and files. |
| Pin (an entry) | 固定 | As chats and browsers pin: it stays at the top. |
| Pin (a screenshot to the screen) | 钉住, 钉在屏幕上 | Another act than pinning an entry: the picture is nailed over the windows. |
| Record (the history) | 记录 | Keeps “录制” for what is recorded live. |
| Record Hotkey | 录制快捷键 | The usual label on a key recorder. |
| Dictation | 听写 | The system's word on macOS and Windows; “语音输入” is kept free for input methods. |
| Hold-to-Talk | 按住说话 | As every chat application labels it. |
| Type as You Speak | 边说边输入 | Says what happens, in the pattern 边…边…. |
| Polish (dictated text, with AI) | 润色 | The editing word; “优化” says nothing. |
| Clean Up (a polish mode) | 整理 | Tidying without rewriting, which is what it does. |
| Vocabulary | 词汇表 | A list of words, not a dictionary (“词典”). |
| Speech Recognition | 语音识别 | Standard. |
| Engine (what is downloaded to recognize speech or text, or to find by meaning) | 引擎 | Standard; the speech engine is 语音识别引擎, as Speech Recognition says. |
| Audio recorder (the program dictation records with) | 录音程序 | A program to install, not the microphone (麦克风). |
| Text Recognition (OCR) | 文字识别 | Standard; “文字” throughout for text in a picture. |
| Screenshot | 截图 | Standard. |
| Selection (of a screenshot) | 选区 | As image editors say it. |
| Live Activity | 实时活动 | Apple's Chinese for the same thing. |
| Find by Meaning | 按含义查找 | Plain words; “语义搜索” is jargon. |
| Local Model | 本地模型 | Standard. |
| Renderer | 渲染器 | Standard. |
| Preferences (of an extension) | 偏好设置 | Distinct from Heyo's own 设置. |
| Settings | 设置 | Standard. |
| Permission | 权限 | Standard. |
| Revoke | 撤销 | Shared with Undo, as systems do; context tells them apart. |
| Theme | 主题 | Standard. |
| System (follow the system) | 跟随系统 | “系统” alone does not say that it follows. |
| Input method | 输入法 | Standard. |
| Uninstall / Remove | 卸载 / 移除 | Uninstall for an extension, Remove for an item of a list. |
| Copy | 复制 | The word Linux and Windows desktops use; no “拷贝”. |
| Click | 点击 | As above; no “点按”. |
| In Progress (the section) | 进行中 | What is under way; quoted as “进行中” in a sentence. |
| Keep Awake | 保持唤醒 | Says the state that is kept; “防休眠” is among the command's keywords. |
| Sleep (the computer) | 睡眠 | The system's word; “休眠” is hibernation. |
| Log Out | 注销 | As Windows and GNOME say it. |
| Trash, Recycle Bin | 回收站 | What every Chinese desktop but macOS calls it. |
| Display (a monitor) | 显示器 | Standard. |
| Kill Process | 结束进程 | As task managers label it; “杀进程” is among its keywords. |
| Emoji | 表情 | What input methods call them. |
| Half, Third, Quarter (of the screen) | 半屏, 三分之一, 四分之一 | As tiling tools say it. |
| First, Last (Third, Two Thirds) | 左侧, 右侧 | The layouts go from the left; “第一个” says nothing of where. |
| System (a command's group) | 系统 | The commands that act on the computer; a message of its own (`command group`), since “System” alone is 跟随系统. |
| Heyo Settings → Dictation (a path through the settings) | “Heyo 设置”→“听写” | Each step quoted, no spaces round the arrow. |

Names stay as they are: Heyo, Claude, Raycast, Wayland, GNOME Shell,
Node.js, SenseVoice, PaddleOCR, and the names of keys (Enter, Esc, Ctrl).
A command's title quoted in a sentence is the title the root search shows,
in “ ”: the two are one message, or say the same.

A message that is a list apart by commas (“paste, copy, pasteboard”) is a
command's search keywords. Its translation is not a translation word for
word: it is the words someone would type in Chinese to find that command
(“截图”, “截屏” for Capture Screenshot), apart by “, ” as the English is.
The English ones find the command whatever the language, so they are not
repeated; and never pinyin.

A phrase that begins with a small letter and a verb (“read your clipboard
history”) is what a permission allows: it is put after “允许“…”” and its
like, so it begins with the verb and has no full stop.
A command's title quoted in a sentence is put in as the root search shows
it (`translate` of the host's title), not written into the sentence.

What a user types stays as it is typed, in every language: the
calculator's syntax (`5 km in mi`), a timer's length (`25m`), the
placeholders of a link or a snippet (`{query}`), a snippet's keyword.
Units written as symbols (km, MB, °C) stay; units written as words (days,
cups) and the places a time is asked for are translated. In the web view
and the runtime a command's title quoted in a sentence is put into it
(`translate` of the host's title), not written into it.

Names stay as they are: Heyo, Claude, Raycast, Wayland, GNOME Shell,
Node.js, SenseVoice, PaddleOCR, and the names of keys (Enter, Esc, Ctrl).
A command's title quoted in a sentence stays English for as long as the
root search shows it in English.
